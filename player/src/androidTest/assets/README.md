# Playback test fixture

`smoke.mp4` is a synthetic moving test pattern generated by `bash tools/generate-demo-videos.sh`, with no recorded app content or external media. It uses 360×640 H.264 Constrained Baseline level 3.0 at 24 fps with a silent AAC audio track. Only the first video frame is a keyframe, so the existing two-second precise-restore assertion still requires decoding from an earlier keyframe.

The previous 1080×1920 High-profile fixture exceeded the API 28 emulator decoder capability. This lower-resolution fixture keeps the existing behavior assertions and does not replace either video in the sample app. It is for functional playback tests, not decoder performance or high-resolution compatibility validation.
